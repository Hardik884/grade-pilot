Build the submission deck.

1. Read `docs/deck-content.md` for the approved slide copy. If it does not exist, stop
   and ask for it - never invent claims about the solution.
2. Use the template at `docs/IDEA_Presentation_Format.pptx`. Do not alter the idea
   detail pointers on each slide.
3. Maximum six slides including the title slide. Points, diagrams and screenshots only -
   no paragraphs.
4. Pull dashboard screenshots from `docs/screenshots/` for the Artifacts slide.
5. Export to PDF. The portal accepts PDF only.
6. Verify: no placeholder text remains, no slide overflows, six slides or fewer.
